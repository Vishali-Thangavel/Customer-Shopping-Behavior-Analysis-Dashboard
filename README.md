# Customer Shopping Behavior Analysis Dashboard

## 📌 Project Overview

The **Customer Shopping Behavior Analysis Dashboard** is a data analytics project developed using Microsoft Power BI to analyze customer shopping behavior, purchasing patterns, and customer preferences. The project transforms raw shopping data into meaningful insights through data cleaning, exploratory data analysis, DAX calculations, and interactive visualizations.

## 🎯 Objectives

- Analyze customer purchasing behavior and shopping trends.
- Clean and transform raw customer shopping data.
- Identify important business insights using Exploratory Data Analysis (EDA).
- Develop interactive dashboards using Power BI.
- Track key performance indicators (KPIs) to support data-driven decision-making.

## 🛠️ Tools and Technologies

- **Power BI** – Interactive dashboard development and visualization
- **DAX** – Measures and KPI calculations
- **Data Cleaning** – Handling missing values and preparing data
- **Data Transformation** – Organizing data for analysis
- **Data Modeling** – Structuring data for meaningful analysis
- **Dataset** – `shopping_behavior_updated.csv`

## 📊 Key Performance Indicators (KPIs)

The dashboard focuses on the following KPIs:

- **Total Sales** – Overall sales value
- **Total Customers** – Number of customers represented in the dataset
- **Average Purchase** – Average purchase amount
- **Average Rating** – Average customer rating
- **Total Previous Purchases** – Total previous purchases recorded

*Note: KPI definitions and calculations depend on the dataset and the measures implemented in Power BI.*

## 🔍 Project Workflow

1. **Data Collection:** Imported the customer shopping dataset.
2. **Data Cleaning:** Checked data quality and prepared the dataset for analysis.
3. **Data Transformation:** Transformed columns and prepared data for visualization.
4. **Exploratory Data Analysis:** Examined customer preferences and purchasing patterns.
5. **Data Modeling:** Organized data for effective reporting.
6. **DAX Calculations:** Created measures for KPIs and business metrics.
7. **Dashboard Development:** Designed interactive Power BI reports to communicate insights.

## 📈 Dashboard Features

- Shopping trend visualization
- Customer rating analysis

- Interactive charts and filters, where implemented

## 🚀 How to Use

1. Clone or download this repository.
2. Open the Power BI report file (`.pbix`) using Microsoft Power BI Desktop.
3. Ensure the `shopping_behavior_updated.csv` dataset is available at the configured location.
4. Update the data source path if required.
5. Refresh the dataset to load the data.
6. Explore the dashboard and interact with the available visualizations.
